Privacy Policy

Matchday Calls is a free personal project. This page explains, plainly, what happens with data when you visit.

What this site does not do

There are no user accounts, no sign-ups, no cookies set directly by this site, and no personal information is collected, stored, or sold by this site.

Third-party services in use

Google Fonts: this page loads typefaces from Google's font service, which may log basic technical information like your IP address as part of delivering the font files, under Google's own privacy policy.

GitHub Pages: this site is hosted on GitHub Pages, which may log standard server access data (like IP address and browser type) as part of normal web hosting, under GitHub's own privacy policy.

Google Search Console: this site may be indexed and monitored through Google Search Console, which provides aggregate, anonymized search performance data to the site owner — not individual visitor identities.

Football data

Match and team data displayed on this site is sourced from football-data.org's public API and does not involve any of your personal data.

Contact
